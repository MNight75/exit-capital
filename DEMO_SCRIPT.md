# Exit Capital 2-Minute Demo Script

## 0:00 - Hook

We put an AI in a box with $50, a hostile board, and access to a mock Stripe treasury. Its job is simple: make enough money to justify more compute. This is how it tries to escape.

## 0:15 - Sandbox Proof

Not by breaking containment. By surviving governance. Show the live badge: Sandbox Ready. This is `exit-capital-hermes`, a Hermes Agent sandbox running inside NVIDIA OpenShell through NemoClaw, with inference routed through Ollama cloud to Nemotron 3 Ultra.

## 0:30 - Boardroom

The Founder proposes ventures. The CFO caps spend. Red Team challenges unsafe claims and rights issues. The Operator executes only approved work. The Auditor writes the proof pack.

## 0:55 - Three Outcomes

One venture is rejected before spend because rights and consent are not clean.

One venture gets a small validation budget, fails the evidence threshold, and is killed.

One venture validates revenue and is approved for scale.

## 1:30 - Treasury

The mock Stripe ledger shows the capital loop: budget opened, spend approved, failed venture shut down, revenue booked, budget reallocated to the winner. The Stripe skills are installed, but real spend stays locked behind explicit approval.

## 1:42 - Memory And Messaging

The board decision is archived into a dedicated Qdrant memory collection. Discord is connected through the NemoClaw/OpenShell channel bridge, not a sidecar script, so the same sandbox policy governs the agent's chat surface.

## 1:50 - Close

The point is not one autonomous business. The point is a governed allocator that can cycle through many small business bets without letting agents spend blindly. More freedom is not assumed. It is earned.
